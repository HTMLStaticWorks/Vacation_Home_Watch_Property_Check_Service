1. Introduction & Overview

HOMEHAVEN WATCH is a complete, premium, production-quality HTML5 website template built specifically for professional vacation home watch, property check, and seasonal residential care businesses.

Key Highlights:
  • 28 Full HTML Pages: Dual distinct homepages, 7 dedicated service pages, pricing matrix, checklists, guides, and auth mockups.
  • Full Light & Dark Mode: Persistent theme switching using `localStorage` and system preference detection.
  • Interactive Components: Live checklist completion meter with print stylesheet, pricing cadence toggle, and FAQ live search.
  • Zero Framework Overhead: Built purely with HTML5, Bootstrap 5.3, Vanilla CSS3, Vanilla JS, and GSAP.

3. Color Palette & CSS Custom Properties

All brand colors and typography variables are configured at the top of assets/css/style.css in the :root selector. 

:root {
  /* Brand Primary Colors */
  --brand-navy: #122232;
  --brand-navy-light: #1D344B;
  --brand-sage: #2C5E47;
  --brand-brass: #C29627;
  --brand-brass-glow: rgba(194, 150, 39, 0.25);

  /* Surfaces & Text */
  --bg-primary: #FAFAF7;
  --bg-surface: #FFFFFF;
  --text-primary: #14202E;
  --text-secondary: #4A5B6D;
  --border-color: rgba(20, 32, 46, 0.1);

  /* Typography */
  --font-heading: 'Manrope', sans-serif;
  --font-body: 'DM Sans', sans-serif;
  --font-serif: 'DM Serif Display', serif;
}

4. Light & Dark Theme Engine

The theme toggle in main.js sets data-bs-theme="dark" on the root <html> element and saves the state in localStorage under 'homehaven_theme'.

5. Core Interactive Components

  • Interactive Checklist: Real-time percentage counter automatically updates upon clicking any item on property-watch-checklist.html.
  • Dynamic Pricing Toggle: Toggles between bi-weekly, weekly, and monthly rates via data-frequency attributes.
  • FAQ Search & Category Filter: Filters questions instantly as the user types or clicks category buttons.
  • Accessible Navigation: Sticky blur navbar with ESC key and outside-click mobile collapse handlers.

6. Form Validation & Feedback

All inquiry and authentication forms include HTML5 client-side validation styled with Bootstrap classes. Submitting valid forms displays accessible feedback alerts without requiring an active backend or directing to fake dashboards.
