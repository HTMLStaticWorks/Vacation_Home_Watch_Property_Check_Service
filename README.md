## 🚀 Key Features

1. **Dual Complete Homepages**:
   - `index.html`: High-converting, trust-focused layout with floating inspection cards, 4-step timeline, and scenario spotlights.
   - `home-2.html`: High-end editorial magazine layout with asymmetric hero, horizontal inspection journey, and category matrix.

2. **Homeowner Dashboard (`dashboard.html`)**:
   - Left-hand full-height side menu from top to bottom.
   - **Visit Scheduling**: Departure/return date picker, frequency selector, inspector assignment, and special instructions.
   - **Inspection Reports**: 18-point visual checklist results, timestamped & GPS-tagged photo gallery with interactive zoom lightbox, inspector sign-off.
   - **Mail & Package Tracking**: Real-time intake table, secure lockbox holding verification, and forwarding requests.
   - **Billing & Subscriptions**: Plan manager, card on file, and downloadable invoice PDFs.

3. **Full Right-to-Left (RTL) Layout Compatibility**:
   - Dedicated RTL button in navbar with smooth direction toggling.
   - Complete CSS bidirectional rules (`[dir="rtl"]`) for Arabic, Hebrew, and Persian.
   - State persisted in `localStorage`.

4. **Full Light / Dark Mode System**:
   - CSS custom variables powering both light and dark themes (including pure white footer in light mode).
   - Automatically detects system preference (`prefers-color-scheme`) and persists state across all pages.


3. **Interactive Tools & Widgets**:
   - **Interactive Checklist Tool**: Live completion percentage calculation, item counters, category groupings, and instant print styling (`window.print()`).
   - **Pricing Cadence Switcher**: Instant switching between bi-weekly, weekly, and monthly rates.
   - **Live FAQ Search & Category Filter**: Real-time filtering without page reloads.
   - **Blog Category Filter**: Instant category filtering and search input.

4. **Responsive & Accessible**:
   - Mobile offcanvas/collapse hamburger menu with multi-level dropdowns.
   - Keyboard accessible navigation, focus rings, ARIA tags, and ESC key closure.
   - Respects `prefers-reduced-motion` for GSAP animations.

5. **Standalone Authentication Demos**:
   - Client-side validated Login, Signup, and Forgot Password pages with feedback alerts.
   - Strictly standalone demonstrations (no backend or fake dashboards).

## 💻 How to Run Locally

Open any `.html` file directly in a modern web browser, or serve via a local development server:

```bash
# Using Python (if available):
python -m http.server 8080

# Using Node (if available):
npx serve .
```

Navigate to `http://localhost:8080/index.html`.
